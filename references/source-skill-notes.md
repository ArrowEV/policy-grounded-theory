# 来源与改造说明

本工具在政策文本研究中整合并改造了以下通用 skill 的工作流思想：

- [grad-grounded-theory](https://github.com/asgard-ai-platform/skills)：理论抽样、持续比较、饱和度与备忘录。
- [tw-research-grounded-theory](https://github.com/FW1201/tw-research-skills)：中文编码流程、范畴关系整理与饱和度评估表达。

以上链接依据本地安装记录保留，用于说明来源；本仓库不捆绑上游 skill，使用本包无需安装它们。上游作品的权利与许可由各自作者及仓库声明确定，本仓库的许可不替代上游许可。

本包增加或组织的操作包括：政策条款及来源锚定、行动导向标签、经验与理论缺口诊断、螺旋迭代理论抽样、知识线记录，以及制度和执行材料独立编码后的功能对应比较。

方法取向需要由研究者明确选择。Charmaz 取向是本工具的默认工作设定；Strauss 与 Corbin 的范式仅作为有条件的分析资源，不将不同流派视为完全相同的方法。

本发布包不包含具体研究项目的题目、原始研究材料、编码结果、预设政策工具清单、内部文件名或个人路径。
